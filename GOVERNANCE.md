# Governance

OpenPlait uses a maintainer-led, consensus-seeking governance model.

Maintainers steward releases, schemas, compatibility promises, and repository
access. Decisions should be made in public issues or RFC pull requests. When
consensus cannot be reached, maintainers may decide by simple majority while
recording the alternatives and rationale.

## API decisions

Changes to portable semantics, versioning rules, security guarantees, or
conformance requirements require an RFC and two maintainer approvals. Backend-
specific behavior belongs in namespaced extensions or adapter packages unless
it has demonstrated portable semantics.

## Maintainers

Maintainers are added or removed by a two-thirds vote of current maintainers,
based on sustained technical contribution and community conduct. A canonical
maintainer list will be added before the first public release.
