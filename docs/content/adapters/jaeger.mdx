# Jaeger Adapter

Talks to Jaeger's Query HTTP API (`/api/services`, `/api/traces`,
`/api/traces/{id}`). Jaeger has no TraceQL equivalent — semantic search is
service-scoped and returns normalized span rows.

- **TypeScript:** `@openplait/adapter-jaeger` — full semantic search + helpers
- **Python:** `openplait.adapters.JaegerAdapter` — semantic search + `list_services`

## Configure

<LangTabs ariaLabel="Configure Jaeger language">
  <LangTab label="TypeScript">

```ts
import { JaegerAdapter } from "@openplait/adapter-jaeger";

const adapter = new JaegerAdapter({
  url: "http://localhost:16686",
  bearerToken: process.env.JAEGER_TOKEN,
  maxResultRows: 1_000,
  perServiceLimit: 100,
});
```

  </LangTab>
  <LangTab label="Python">

```python
import os
from openplait.adapters import JaegerAdapter, JaegerConfig

adapter = JaegerAdapter(
    JaegerConfig(
        url="http://localhost:16686",
        bearer_token=os.environ.get("JAEGER_TOKEN"),
        max_result_rows=1_000,
        per_service_limit=100,
    )
)
```

  </LangTab>
</LangTabs>

Authentication options are bearer token, username/password, or custom HTTP
headers. When the Query UI is mounted under `/jaeger`, service discovery retries
with that path prefix (`resolved_url` / `resolvedUrl`).

## Semantic trace search

A `service.name` equals filter is required because Jaeger's search API is
service-scoped:

<LangTabs ariaLabel="Jaeger semantic query language">
  <LangTab label="TypeScript">

```ts
const traces = {
  apiVersion: "openplait.io/v1alpha1",
  kind: "Query",
  metadata: { name: "checkout-spans" },
  spec: {
    mode: "semantic",
    datasource: { kind: "JaegerDatasource", name: "jaeger-local" },
    input: { signal: "traces", entity: "jaeger.traces" },
    timeRange: { field: "timestamp", from: "${__from}", to: "${__to}" },
    select: [
      { field: "trace.id" },
      { field: "span.id" },
      { field: "service.name" },
      { field: "span.name" },
    ],
    where: {
      and: [{ field: "service.name", operator: "equals", value: "checkout" }],
    },
    limit: 100,
  },
};
```

  </LangTab>
  <LangTab label="Python">

```python
from openplait import OPENPLAIT_API_VERSION
from openplait.core import parse_query

query = parse_query(
    {
        "apiVersion": OPENPLAIT_API_VERSION,
        "kind": "Query",
        "metadata": {"name": "checkout-spans"},
        "spec": {
            "mode": "semantic",
            "datasource": {"kind": "JaegerDatasource", "name": "jaeger-local"},
            "input": {"signal": "traces", "entity": "jaeger.traces"},
            "timeRange": {
                "field": "timestamp",
                "from": "2026-08-05T00:00:00Z",
                "to": "2026-08-05T01:00:00Z",
            },
            "select": [{"field": "trace.id"}, {"field": "service.name"}],
            "where": {
                "field": "service.name",
                "operator": "equals",
                "value": "checkout",
            },
            "limit": 100,
        },
    }
)
result = await adapter.execute(query)
```

  </LangTab>
</LangTabs>
