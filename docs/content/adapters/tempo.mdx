# Grafana Tempo Adapter

Generic Tempo adapter with no product-specific field assumptions.

- **TypeScript:** `@openplait/adapter-tempo` — semantic + TraceQL, version inspect
- **Python:** `openplait.adapters.TempoAdapter` — native TraceQL `/api/search`

## Configure

<LangTabs ariaLabel="Configure Tempo language">
  <LangTab label="TypeScript">

```ts
import { TempoAdapter } from "@openplait/adapter-tempo";

const adapter = new TempoAdapter({
  url: "https://tempo.example.com",
  tenantId: "tenant-a",
  bearerToken: process.env.TEMPO_TOKEN,
  maxResultRows: 1_000,
  maxTimeRangeMs: 7 * 24 * 60 * 60 * 1_000,
  tempoVersion: "2.8.2",
});
```

  </LangTab>
  <LangTab label="Python">

```python
import os
from openplait.adapters import TempoAdapter, TempoConfig

adapter = TempoAdapter(
    TempoConfig(
        url="https://tempo.example.com",
        tenant_id="tenant-a",
        bearer_token=os.environ.get("TEMPO_TOKEN"),
        allow_native_queries=True,
        max_result_rows=1_000,
    )
)
```

  </LangTab>
</LangTabs>

Authentication options are bearer token, username/password, or custom HTTP
headers. `tenantId` / `tenant_id` is sent as Tempo's `X-Scope-OrgID` header.

## Native TraceQL

<LangTabs ariaLabel="Native Tempo query language">
  <LangTab label="TypeScript">

```ts
const query = {
  apiVersion: "openplait.io/v1alpha1",
  kind: "Query",
  metadata: { name: "checkout-traces" },
  spec: {
    mode: "native",
    datasource: { kind: "TempoDatasource", name: "tempo" },
    native: {
      language: "traceql",
      statement: '{ resource.service.name = "checkout" }',
    },
    extensions: {
      "io.openplait.tempo": {
        timeRange: { from: "2026-08-05T00:00:00Z", to: "2026-08-05T01:00:00Z" },
        limit: 20,
      },
    },
  },
};
```

  </LangTab>
  <LangTab label="Python">

```python
from openplait import OPENPLAIT_API_VERSION
from openplait.core import parse_query

query = parse_query(
    {
        "apiVersion": OPENPLAIT_API_VERSION,
        "kind": "Query",
        "metadata": {"name": "checkout-traces"},
        "spec": {
            "mode": "native",
            "datasource": {"kind": "TempoDatasource", "name": "tempo"},
            "native": {
                "language": "traceql",
                "statement": '{ resource.service.name = "checkout" }',
            },
            "extensions": {
                "io.openplait.tempo": {
                    "timeRange": {
                        "from": "2026-08-05T00:00:00Z",
                        "to": "2026-08-05T01:00:00Z",
                    },
                    "limit": 20,
                }
            },
        },
    }
)
```

  </LangTab>
</LangTabs>

TypeScript also supports `inspectServer()`, semantic compile with attribute
mappings, and TraceQL metrics when the Tempo version supports them.
